# 📚 Study OS

Modern, web tabanlı bir çalışma dashboard'u.

## 🚀 Özellikler

- 📚 Flashcard sistemi (localStorage tabanlı)
- 🎯 Quiz modu (doğru/yanlış takibi)
- ⏱ Pomodoro timer (50/10 çalışma döngüsü)
- 🌤 Canlı hava durumu (API entegre)
- 🌙 Dark / Light tema
- 🎵 Spotify hızlı erişim
- 📁 Google Drive entegrasyonu

## 🧠 Amaç

Bu proje, günlük çalışma verimini artırmak için tasarlanmış mini bir “kişisel öğrenme sistemi”dir.

## 🛠 Teknolojiler

- HTML5
- CSS3 (modern glassmorphism UI)
- Vanilla JavaScript
- LocalStorage API
- OpenWeatherMap API
